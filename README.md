# JabLab

**Solo boks / shadow boxing koçu.**

Shadow boxing'ini tam-vücut izler; gard, duruş, kombinasyon sırası ve denge için köşendeki antrenör gibi kısa sesli düzeltmeler verir.

Ortak ilke: on-device pose analizi + deterministik kural motoru — gerçek-zamanlı LLM yok, ham video cihazdan çıkmaz, düşük güvende hüküm yok, her karar açıklanabilir.
